# Blender-CoD

A Blender plugin for importing and exporting formats used by CoD mod tools.

Forked from [CoDEmanX/blender-cod](https://github.com/CoDEmanX/blender-cod).

## Requirements

- Blender 5.1 or above

## Supported Formats

- `.XMODEL_EXPORT`
- `.XMODEL_BIN`
- `.XANIM_EXPORT`
- `.XANIM_BIN`
